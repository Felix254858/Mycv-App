Professional CV & Portfolio App

About the App

The Professional CV & Portfolio App is a project designed to present my professional profile, technical skills, educational background, work experience, and projects in one place.

The purpose of this application is to help employers, recruiters, and potential clients learn more about my qualifications and abilities. It serves as a digital portfolio where I can showcase my ICT knowledge, demonstrate my coding skills, and share my professional journey.

This project is part of my continuous learning and development in Information and Communication Technology (ICT).

Features

- Professional profile and introduction
- Educational background
- Technical skills and competencies
- Work experience
- Projects and portfolio showcase
- Contact information
- Responsive design for different screen sizes

Technologies Used

- HTML5 — page structure
- CSS3 — styling and layout
- JavaScript — interactive features

Getting Started

To view or run this project locally:

1. Clone or download this repository.
2. Open the project folder.
3. Locate the "index.html" file.
4. Open it in your web browser.
